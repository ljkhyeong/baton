# ADR-0023: 결정·자료의 불변 수정 이력

- 상태: 채택
- 결정일: 2026-09-05

## 결정

결정·역할 자료의 수정 전후 값을 담당 변경 조정자에서 비교하고 원본과 같은 트랜잭션으로 저장한다.
JPA 엔티티 이벤트나 공통 HTTP 필터에서 업무 변경을 추정하지 않는다. 이력은 별도 부모 행과 순서가 있는
필드 행으로 저장하며, 조회에서는 최근 50개 식별자와 해당 필드를 각각 일괄 조회해 컬렉션 페이지네이션을 피한다.

현재 계정 조회 포트로 확인한 계정 식별자·표시 이름을 스냅샷으로 남긴다. 비로그인 공유 키 사용은
인증된 개인으로 추정하지 않는다. 원본이 보관되거나 시즌이 종료돼도 현재 읽기 권한으로 조회한다.

## 범위

V36 적용 이후의 실제 수정·보관·복원만 기록한다. 기존 기록의 과거 값을 만들거나 모든 엔티티로
자동 확장하지 않는다. 같은 값의 재저장과 실패한 변경은 이력을 추가하지 않는다.
