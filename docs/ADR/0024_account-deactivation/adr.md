# ADR-0024: 조직 기록을 보존하는 계정 비활성화

- 상태: 채택
- 결정일: 2026-09-05

## 결정

계정에 nullable 비활성 시각을 추가한다. 비활성화는 계정 세션 버전을 증가시키고 로그인·세션 조회에서 비활성 계정을 제외한다. 기존 외부 신원도 다시 로그인할 수 없다. 신원·비밀번호·팀 기록·구성원 활동 상태는 삭제하거나 변경하지 않는다.

비활성화는 참여 팀의 식별자를 먼저 조회한 뒤 식별자 순으로 팀 배타 잠금을 잡고 계정 배타 잠금, 멤버십 잠금 순으로 처리한다. `READ_COMMITTED`에서 잠금 후 현재 멤버십과 관리자 상태를 다시 확인한다. 잠금 전에 발견하지 못한 팀 연결이 있으면 전체 요청을 충돌로 돌려 다시 시도하게 한다. 어느 팀의 마지막 활성 관리자도 제거하지 않는다.

새 권한 부여와 초대 수락은 팀 잠금 뒤 대상 계정 잠금에서 활성 여부를 확인한다. 기존 공유 키의 구성원 연결은 별도 저장 트랜잭션이므로 계정 잠금과 마지막 활성 검증을 실제 삽입 트랜잭션에 둔다. 부모 트랜잭션의 계정 잠금으로 자식 삽입의 FK 검사를 막지 않는다.

계정 권한 회수·감사 이력·비활성 상태·CAL 구독 해지 예약은 함께 커밋한다. CAL의 기존 해지 처리기는 비활성 계정의 늦게 생성된 구독도 회수한다. ROUND·BRIEF·CAL의 활성 멤버십 확인은 계정 상태를 함께 확인한다.

## 한계

공유 접근 키와 이미 발급된 ROUND 참여권은 별도 수명주기를 유지한다. CAL의 실제 외부 폐기는 비동기 재시도로 완료한다. 직접 재활성화와 개인정보 삭제를 포함한 완전 탈퇴는 별도 제품 계약이 필요하다.
